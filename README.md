# May Bike ERP V11 PWA

Arquivos prontos para publicar no GitHub Pages, Netlify ou Vercel.

## Login inicial
- Usuário: `admin`
- Senha: `admin`

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `maybike-erp`.
2. Envie todos os arquivos desta pasta para o repositório.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/root`.
6. Abra o link gerado pelo GitHub Pages.
7. No Chrome/Edge, clique em **Instalar** ou no botão **⬇️ Instalar** dentro do sistema.

## Importante
O PWA precisa estar hospedado em HTTPS para instalar corretamente. GitHub Pages, Netlify e Vercel já fornecem HTTPS grátis.
